# Excel export with original payment screenshots

This patch adds a real `.xlsx` report because CSV files cannot embed images.

## What changes

The report page gets a new **Download Excel + screenshots** button.

The Excel workbook contains:
- Report type and reporting period
- Total spend
- Transaction count
- WeChat total
- Alipay total
- A structured transaction table
- A TOTAL row generated by the Excel table
- The original uploaded Alipay/WeChat screenshot embedded in the same row as each transaction

This makes it possible to compare the OCR/extracted fields with the original source image directly in Excel.

## Files to replace

Replace these individual files only:

- `apps/api/package.json`
- `apps/api/src/index.js`
- `apps/web/app/page.js`

Do not replace the entire `apps/api` or `apps/web` directories.

## Rebuild

Because the API now uses `exceljs`, rebuild both API and web:

```bash
docker compose up -d --build api web
```

Then check:

```bash
docker compose ps
docker compose logs api --tail=100
```

## Notes

- No PostgreSQL schema change is required.
- Existing saved expenses work automatically if their `image_path` still points to a file in `storage/uploads`.
- PNG and JPEG screenshots are embedded. If an older image is missing or in an unsupported image format, the Excel cell will say so instead of failing the whole export.
- Excel files can become large because they contain the original screenshots.
