# Start here: Oak development and operations

Read the [beginner-friendly developer and operations handbook](docs/handbook/README.md).

It covers Git setup, architecture, staging, code approval/deployment, business-data sync, company funds, backups, recovery, troubleshooting, command reference and the remaining roadmap.

Use VPS for normal real data entry. Use Mac staging for new code and test data. Code release and data synchronization are separate processes. The unfinished strict production write lock is not enabled.
