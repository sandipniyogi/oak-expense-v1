# Oak Social Studio v1

New additive module:

- `docker-compose.social.yml`
- `services/social-api/` (PostgreSQL + Ollama + FFmpeg/Sharp rendering)
- `/social` dashboard
- `/social/media` media library
- `/social/create` local-AI campaign creator
- `/social/projects/[id]` editable content/video project
- `/social/calendar` approval/scheduling workflow
- `/social/admin` brand rules + weekly Social Agent
- staging/production start scripts and smoke test

No Expense, OCR or Inventory source file is replaced by this patch.
